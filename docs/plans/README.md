# Plans

Planning artifacts (roadmap, milestones, large feature plans). Each plan lives in its own file under `ai/plans/` following `plan-conventions.md`.

## Milestones

- **M1 — Conversational Infrastructure:** Telegram bot registration, webhook handling, message routing, FSM state management.
- **M2 — Spreadsheet Binding (Release 1 MVP):** OAuth connection, file/sheet selection, column mapping, category confirmation.
- **M3 — Expense Registration (Release 1 MVP):** Free-text input, NLP extraction, amount/currency detection, category assignment, confirmation flow, save with reference, undo.
- **M4 — Enhanced Features (Release 2):** Multiple expenses per message, voice messages, relative dates, payment method detection, low-confidence transcription handling.
