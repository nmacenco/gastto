### Task T-E1-US-04-02: Define classification result value object

- **Description:** Create an immutable domain value object that represents the outcome of a category classification attempt. It must carry the inferred canonical category, a normalized confidence score, an ambiguity flag, and a flag indicating whether the result was a fallback because the inferred category was not available in the user's spreadsheet.

- **Architectural layer:** `Domain`

- **Acceptance criteria:**

  - [x] It supports a "no match" state without using `null` or `undefined` for business meaning.
  - [x] It is covered by unit tests for construction and state transitions.
