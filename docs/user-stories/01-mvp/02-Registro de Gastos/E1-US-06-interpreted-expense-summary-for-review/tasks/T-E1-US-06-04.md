### Task T-E1-US-06-04: Implement timeout, reminder, and auto-cancel flow

- **Description:** Implement the timeout management for the "awaiting summary confirmation" state. Using the existing conversational state mechanism (HU-0.04), set a 10-minute timer when the summary is presented. After 10 minutes without user response, trigger a single reminder notification asking "¿Confirmamos el registro?" / "Shall we confirm the entry?". If another 10 minutes pass without response, automatically cancel the expense registration and notify the user. All timeout logic belongs in the Application layer — the use case decides what to do, the presenter shows it.

- **Architectural layer:** `Application`

- **Acceptance criteria:**
  - [ ] 10-minute timeout is set when the summary is presented.
  - [ ] A single reminder is sent after the first timeout.
  - [ ] A second 10-minute timeout triggers automatic cancellation.
  - [ ] Cancellation cleans up the conversation state.
  - [ ] User responses received within the timeout reset or proceed normally.
  - [ ] Timeout durations (10 min + 10 min) are configurable constants.
