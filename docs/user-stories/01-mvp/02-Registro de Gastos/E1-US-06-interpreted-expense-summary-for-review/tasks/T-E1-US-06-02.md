### Task T-E1-US-06-02: Implement expense summary formatting with confidence markers

- **Description:** Implement the `GenerateExpenseSummaryUseCase` in `src/application/use-cases/expense/`. This use case receives the interpreted expense data (from E1-US-03/04/05) and builds an `ExpenseSummary` DTO. It must: (1) always include the five fields (concept, amount, currency, category, date), (2) set date to "today" when not detected, (3) mark the category field with a low-confidence flag when confidence is below a configurable threshold, (4) include action options (confirm/correct/cancel) as part of the summary metadata. The use case calls the presenter interface — it never directly formats platform-specific output.
