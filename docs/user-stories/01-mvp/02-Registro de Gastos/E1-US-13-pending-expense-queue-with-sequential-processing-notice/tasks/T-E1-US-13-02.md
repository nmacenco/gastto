### Task T-E1-US-13-02: Persist the pending expense queue

- **Description:** Add schema-first persistence for the per-user pending expense queue and implement its Drizzle repository adapter. Preserve ordered, durable queue state across worker restarts and make enqueue/dequeue transitions safe from concurrent per-user processing; generate the migration and document the data-model addition.

- **Architectural layer:** `Infrastructure`

- **Acceptance criteria:**
  - [ ] Queue entries persist the owner, raw message, received timestamp, ordering key, and channel/message identity required by the domain contract.
  - [ ] Repository operations atomically append, retrieve the oldest item, remove it, count pending items, and clear only the intended user's queue when required.
  - [ ] Required foreign keys specify `onDelete` and query/FK columns have explicit indexes.
  - [ ] A generated Drizzle migration and `docs/architecture/data-model.md` describe the schema and relationships.
  - [ ] PostgreSQL integration tests prove FIFO persistence and the two-item pending limit under the repository contract.

- **Delivery dependencies (block the merge):** T-E1-US-13-03, T-E1-US-13-05, T-E1-US-13-06
