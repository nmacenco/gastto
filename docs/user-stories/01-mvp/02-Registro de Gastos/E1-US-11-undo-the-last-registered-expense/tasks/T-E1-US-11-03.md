### Task T-E1-US-11-03: Delete a spreadsheet row by saved reference

- **Description:** Implement the Infrastructure adapter operation that deletes a single spreadsheet row using the saved provider, spreadsheet, sheet, and row reference. Map provider responses and failures to the typed Application deletion result; never report success unless the provider confirms the deletion.

- **Architectural layer:** `Infrastructure`

- **Acceptance criteria:**
  - [x] The adapter deletes exactly the referenced row in the referenced Google Sheet for this Google Sheets-only story.
  - [x] A successful provider response maps to the typed deletion success result.
  - [x] Network, authorization, and spreadsheet-structure failures map to typed failures and do not claim deletion succeeded.
  - [x] The adapter does not contain chat wording or Application decision logic.

- **Technical dependencies (block the start):** T-E1-US-11-01; E4 provider deletion operation
- **Delivery dependencies (block the merge):** T-E1-US-11-04, T-E1-US-11-06

- **Estimation:** 2.5 hours

- **Suggested role:** Backend

- **Technical notes:** Mock provider SDK/HTTP boundaries in adapter tests. Preserve the Adapter Pattern defined in ADR-004 and classify external errors consistently with the testing guidelines.
