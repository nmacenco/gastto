### Task T-E1-US-03-01: Define Money and Currency domain value objects

- **Description:** Create the `Money` and `Currency` value objects in the `src/domain/value-objects/` directory. `Money` should encapsulate an amount (as a decimal-safe type, e.g., `string` or `BigDecimal`) and a `Currency` instance. `Currency` should normalize both ISO codes (EUR, USD, ARS) and recognized symbols ($, €, £). Define validation rules for the amount (non-negative or zero handling) and the currency code.

- **Architectural layer:** `Domain`

- **Acceptance criteria:**
  - [ ] `Currency` value object exists and normalizes ISO codes and symbols.
  - [ ] `Money` value object exists and validates amount and currency.
  - [ ] Invalid or unsupported currencies raise a domain error.
  - [ ] `Money` supports an amount of zero without silently rejecting it.

- **Technical dependencies (block the start):** None
- **Delivery dependencies (block the merge):** T-E1-US-03-02

- **Estimation:** 2 hours

- **Suggested role:** Backend

- **Technical notes:** Use the existing `src/domain/value-objects/` layout. Avoid `number` for amounts to prevent floating-point errors; prefer `string` or a BigDecimal wrapper. Refer to `docs/architecture/data-model.md` for current data types.
