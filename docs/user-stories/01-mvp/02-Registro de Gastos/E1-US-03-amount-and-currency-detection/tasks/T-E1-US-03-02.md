### Task T-E1-US-03-02: Define extraction result and failure types

- **Description:** Define the `AmountCurrencyExtractionResult` type and the possible failure modes in the `src/domain/` layer. Success should carry a `Money` instance and metadata (e.g., raw matched text). Failures should model: `AmountNotFound`, `CurrencyNotFound`, `AmbiguousCurrency` (symbol like `$` without default fallback), and `InvalidAmountFormat`. These types will be used by the application service and the conversation use cases to decide the next step.

- **Architectural layer:** `Domain`

- **Acceptance criteria:**
  - [ ] Result and failure types are immutably defined.
  - [ ] Success variant carries a `Money` value object.
  - [ ] Failure variants are exhaustive enough to drive the clarification flow.

- **Delivery dependencies (block the merge):** T-E1-US-03-03

- **Estimation:** 1 hour

- **Suggested role:** Backend
