### Task T-E1-US-04-01: Define category and keyword vocabulary domain model

- **Description:** Create domain value objects and entities for the category assignment system. Define `Category` (immutable value object with name and aliases), `KeywordMapping` (links a set of keywords to a category with a weight), and `Confidence` (enum or value object with levels: `high`, `medium`, `low`, `none`). Create the base category vocabulary as a domain constant or configuration object covering the MVP-required categories: food, transportation, housing, health, entertainment, services — each with a set of Spanish keywords (e.g., `almuerzo`, `comida`, `cena` → food; `combustible`, `gasolina`, `taxi` → transportation). Ensure the vocabulary is extensible (e.g., a `CategoryVocabulary` class with `addCategory` and `getKeywords` methods).

- **Architectural layer:** `Domain`

- **Acceptance criteria:**
  - [ ] `Category` value object exists with `name`, `aliases`, `spreadsheetEquivalent` fields.
  - [ ] `Confidence` value object exists with levels: `high`, `medium`, `low`, `none`.
  - [ ] `KeywordMapping` entity or typed map links keyword strings to `Category` references.
  - [ ] `CategoryVocabulary` class with the MVP base categories (food, transportation, housing, health, entertainment, services) pre-populated with Spanish keywords.
  - [ ] `CategoryVocabulary` supports adding new categories and keywords at runtime.
  - [ ] Unit tests verify vocabulary construction and keyword lookup.

- **Technical dependencies (block the start):** None
- **Delivery dependencies (block the merge):** T-E1-US-04-02, T-E1-US-04-03

- **Estimation:** 2 hours

- **Suggested role:** Backend

- **Technical notes:**
  - Follow existing value object pattern in `src/domain/value-objects/` (see `MessageType.ts` for union type patterns).
  - The base vocabulary is Spanish-only for MVP. Multi-language support is future work.
  - Keywords should be stored in normalized form (lowercase, trimmed).
  - Base vocabulary can be a plain object or class — keep it testable and mutable for later extension.
