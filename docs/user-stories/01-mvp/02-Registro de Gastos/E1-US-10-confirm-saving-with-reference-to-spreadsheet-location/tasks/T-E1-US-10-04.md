### Task T-E1-US-10-04: Render and deliver the location-aware chat confirmation

- **Description:** Implement the chat-facing output adapter/template that renders the Application confirmation in a concise, readable format, including concept, amount, currency, quoted sheet name, and row when supplied. Wire it to the existing confirmation flow without introducing business decisions in the handler.

- **Architectural layer:** `Interfaces`

- **Acceptance criteria:**
  - [ ] The chat message renders a readable location such as `Saved in 'Expenses', row 47`.
  - [ ] The multi-sheet message renders the sheet returned by the save result, not a default sheet.
  - [ ] When the row number is absent, the message names the sheet and contains no malformed row fragment.
  - [ ] The route/webhook handler only deserializes, validates, and delegates to the Application use case.

- **Technical dependencies (block the start):** T-E1-US-10-03
- **Delivery dependencies (block the merge):** T-E1-US-10-05

- **Estimation:** 1.5 hours

- **Suggested role:** Backend

- **Technical notes:** The delivery adapter implements the Application output port. Do not move formatting rules that alter successful/failure behavior into the route handler.
