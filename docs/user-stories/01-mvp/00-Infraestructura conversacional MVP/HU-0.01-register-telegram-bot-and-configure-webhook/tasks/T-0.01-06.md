### Task T-0.01-06: Verify end-to-end webhook latency and retry behavior

- **Description:** Perform a real end-to-end test by sending a message to the bot in the production environment. Verify that the message arrives at the webhook endpoint in less than 2 seconds. Temporarily simulate endpoint unavailability to confirm that Telegram follows its native exponential backoff retry behavior, and that messages are delivered correctly after recovery.

- **Architectural layer:** `Infrastructure`

- **Acceptance criteria:**
  - [ ] End-to-end latency from sending a message to bot delivery is measured at < 2 seconds.
  - [ ] Telegram retry behavior is observed (exponential backoff) when the endpoint returns errors or is temporarily unreachable.
  - [ ] Messages are successfully delivered once the endpoint recovers.

- **Technical dependencies (block the start):** T-0.01-04, T-0.01-05
- **Delivery dependencies (block the merge):** None

- **Estimation:** 1 hour

- **Suggested role:** QA / Backend
