### Task T-0.01-03: Implement Telegram source validation middleware

- **Description:** Implement validation middleware for the Fastify webhook route to verify that incoming requests originate from Telegram. Validate the secret token header (`X-Telegram-Bot-Api-Secret-Token`) or other Telegram-specific validation mechanism. Reject any invalid request with HTTP 403 without processing the request body.

- **Architectural layer:** `Interfaces`

- **Acceptance criteria:**
  - [x] Requests without the expected secret token or with an invalid token receive HTTP 403.
  - [x] Valid Telegram requests pass through to the controller.
  - [x] No message processing occurs for rejected calls.

- **Technical dependencies (block the start):** T-0.01-02
- **Delivery dependencies (block the merge):** T-0.01-05

- **Estimation:** 1 hour

- **Suggested role:** Backend

- **Technical notes:** Register the middleware at the route level in Fastify (e.g., `preHandler` hook). The secret token value must be read from environment variables / secrets, never hardcoded.
