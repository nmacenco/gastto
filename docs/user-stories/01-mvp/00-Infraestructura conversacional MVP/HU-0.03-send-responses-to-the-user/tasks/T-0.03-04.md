### Task T-0.03-04: Implement automatic message chunking for >4096 characters

- **Description:** Add logic to the Telegram sender adapter (or a dedicated helper) that automatically splits text exceeding Telegram's 4096-character limit into coherent fragments and sends them sequentially to the same chat. The splitting should prefer line breaks or sentence boundaries when possible to keep fragments readable.

- **Architectural layer:** `Infrastructure`

- **Acceptance criteria:**
  - [x] Messages with ≤ 4096 characters are sent in a single API call.
  - [x] Messages with > 4096 characters are split into fragments of ≤ 4096 chars each.
  - [x] Fragments are sent sequentially to the same `chat_id`.
  - [x] If any fragment fails permanently (after retries), the remaining fragments are not sent, and the overall operation reports failure.
  - [x] The chunking logic is covered by unit tests.

- **Technical dependencies (block the start):** T-0.03-02
- **Delivery dependencies (block the merge):** T-0.03-05

- **Estimation:** 1.5 hours

- **Suggested role:** Backend

- **Technical notes:** Telegram's limit is 4096 UTF-8 characters. Use `text.length` (JavaScript string length counts UTF-16 code units, which is sufficient for this limit). Split on `\n\n` or `. ` when possible, then fall back to hard cut at the limit. Reuse the retry-enabled sender for each fragment.
