- **Description:** Implement the Interfaces-layer behavior for malformed payloads. When the parser returns `MALFORMED`, the Fastify route handler must log the full raw payload (use the project's logger), respond HTTP 200 to Telegram to prevent infinite retries, and ensure the exception is not propagated to the rest of the system.
