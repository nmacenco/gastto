### Task T-4.07-01: Read unique category values from spreadsheet

- **Description:** Implement an adapter method that queries the user's spreadsheet (via the Sheets/Excel adapter) and extracts the unique non-empty values from the mapped category column. The method must handle large columns efficiently and return a deduplicated list of category names. It must also detect if the column is completely empty to trigger the default-category flow later.

- **Architectural layer:** `Infrastructure`

- **Acceptance criteria:**
  - [ ] Adapter method returns an array of unique strings from the category column.
  - [ ] Empty or whitespace-only cells are excluded.
  - [ ] When the column has no values, the method returns an empty array.
  - [ ] Unit tests mock the external spreadsheet API and verify deduplication logic.

- **Technical dependencies (block the start):** None
- **Delivery dependencies (block the merge):** T-4.07-02, T-4.07-04

- **Estimation:** 1.5 hours

- **Suggested role:** Backend

- **Technical notes:** Reuse the existing Sheets/Excel adapter under `src/infrastructure/adapters/`. Add a new method `getUniqueCategoryValues(spreadsheetId: string, columnMapping: ColumnMapping): Promise<string[]>`. Ensure caching or pagination if the sheet is large. Refer to `AGENTS.md` for Drizzle and adapter conventions.
