### Task T-4.05-05: Implement InferColumnMapping use case

- **Description:** Implement the `InferColumnMapping` use case that orchestrates the column mapping inference flow. The use case: (1) retrieves the OAuth token via `IOAuthTokenRepository` and decrypts it via `TokenEncryptionPort`, (2) loads the `SpreadsheetConfig` via `ISpreadsheetConfigRepository`, (3) extracts the `SpreadsheetPreview` from the FSM state payload (stored by T-4.05-04), (4) invokes `ColumnInferencePort.infer()` with headers (row 1) and sample rows (rows 2–10), (5) persists inferred mappings via `IColumnMappingRepository.upsertMany()` with `inferred: true` and `confirmedAt: null`, (6) formats a proposal message using `onboardingCopies` helpers with emoji indicators per Scenario 1/2, (7) sends the message via `MessagingOutputPort`. For Scenario 3 (no headers), self-transitions to `ONBOARDING_MAPPING` with `step: 'no-header'` and asks the user which row data starts at. For Scenario 4 (unmapped fields), includes omission info in the message. The use case contains ALL business logic; output ports keep it agnostic of Telegram/WhatsApp.

- **Architectural layer:** `Application`

- **Acceptance criteria:**
  - [ ] High-confidence mapping (Scenario 1): message includes emoji indicators (📅💰🏷️📝) and asks "Is this correct?".
  - [ ] Low-confidence mapping (Scenario 2): message includes uncertainty indicator ("I'm not sure about some fields").
  - [ ] No-header detection (Scenario 3): message asks user which row data starts at; state payload updated with `step: 'no-header'`.
  - [ ] Unmapped fields (Scenario 4): message lists omitted fields and offers manual column assignment.
  - [ ] Multi-language headers (Scenario 5): ES/EN/PT headers are recognized and mapped correctly.
  - [ ] Inferred mappings are persisted with `inferred: true` and `confirmedAt: null`.
  - [ ] Token errors (missing/expired/revoked/decrypt failure) send reconnect message and transition to `ONBOARDING_START`.
  - [ ] Missing spreadsheet config sends reconnect message and transitions to `ONBOARDING_START`.
  - [ ] Missing preview in payload falls back gracefully (error message, no crash).
  - [ ] No imports from Infrastructure or Interfaces layers.
  - [ ] Unit tests mock all ports and cover all 5 Gherkin scenarios plus error paths.
