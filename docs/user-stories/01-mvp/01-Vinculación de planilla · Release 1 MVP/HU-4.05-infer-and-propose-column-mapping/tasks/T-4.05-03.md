### Task T-4.05-03: Implement Drizzle column mapping repository

- **Description:** Implement `DrizzleColumnMappingRepository` conforming to `IColumnMappingRepository` defined in `src/domain/ports/repositories.ts`. Implement three methods: `findBySpreadsheetId(spreadsheetId)` which queries `column_mappings` by FK and returns `ColumnMapping[]`; `upsertMany(mappings)` which performs `INSERT ... ON CONFLICT (spreadsheet_id, gastto_field) DO UPDATE` for batch persistence of inferred mappings; and `confirm(id)` which sets `confirmed_at = NOW()` for a given mapping. The DB column `gastto_field` must be mapped to the domain entity's `GasttoField` (capital G) to maintain compatibility with `RegisterExpense.ts` which already uses this naming.
