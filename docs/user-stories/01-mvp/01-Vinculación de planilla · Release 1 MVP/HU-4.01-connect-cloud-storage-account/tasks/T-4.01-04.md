### Task T-4.01-04: Implement OneDrive OAuth adapter

- **Description:** Create the OneDrive adapter that implements `OAuthServicePort`. Handle the full OAuth2 authorization-code flow for Microsoft Identity Platform, including token exchange and error mapping.

- **Architectural layer:** `Infrastructure`

- **Acceptance criteria:**
  - [ ] `OneDriveOAuthAdapter` created in `src/infrastructure/adapters/oauth/OneDriveOAuthAdapter.ts`
  - [ ] Implements `OAuthServicePort`
  - [ ] `buildAuthUrl` generates a valid Microsoft OAuth2 URL with `state`, `redirect_uri`, and required OneDrive scopes
  - [ ] `exchangeCode` exchanges code for tokens via `https://login.microsoftonline.com/common/oauth2/v2.0/token`
  - [ ] Maps Microsoft-specific errors (AADSTS codes, consent denied, etc.) to domain errors
  - [ ] Unit tests mock the Microsoft token endpoint

- **Technical dependencies (block the start):** T-4.01-01
- **Delivery dependencies (block the merge):** T-4.01-06

- **Estimation:** 3 hours

- **Suggested role:** Backend

- **Technical notes:** Required scope: `Files.ReadWrite` or `Files.Read` depending on ADR-004. Microsoft uses `tenant=common` for consumer accounts. Client ID and secret from env vars.
