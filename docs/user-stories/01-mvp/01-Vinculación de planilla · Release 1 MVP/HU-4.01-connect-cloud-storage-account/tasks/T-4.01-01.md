### Task T-4.01-01: Define OAuth service port and domain errors

- **Description:** Create the `OAuthServicePort` interface in the Domain layer so the Application layer can remain agnostic of Google/Microsoft specifics. Define domain errors for all recoverable and unrecoverable OAuth failure modes.

- **Architectural layer:** `Domain`

- **Acceptance criteria:**
  - [ ] `OAuthServicePort` exists in `src/domain/ports/services.ts` (or a new file `src/domain/ports/oauth.ts`) with methods:
    - `buildAuthUrl(provider: SpreadsheetProvider, userId: string, redirectUri: string): string`
    - `exchangeCode(provider: SpreadsheetProvider, code: string, state: string): Promise<{ accessToken: string; refreshToken: string; expiresAt: Date; scope: string[] }>`
  - [ ] Domain errors defined: `OAuthDeniedError`, `OAuthNetworkError`, `InvalidProviderError`, `OAuthStateMismatchError`
  - [ ] All errors extend a common `DomainError` base class or follow the project convention
  - [ ] No external library imports in the Domain layer

- **Technical dependencies (block the start):** None
- **Delivery dependencies (block the merge):** T-4.01-03, T-4.01-04, T-4.01-05, T-4.01-06

- **Estimation:** 2 hours

- **Suggested role:** Backend
