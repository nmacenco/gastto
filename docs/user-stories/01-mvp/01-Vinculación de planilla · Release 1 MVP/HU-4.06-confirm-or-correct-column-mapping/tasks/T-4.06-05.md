### Task T-4.06-05: Implement correct single mapping field use case with column validation

- **Description:** Implement the application use case that applies a single field correction to the proposed mapping. It parses the user's message, validates that the referenced column exists in the spreadsheet via the `SpreadsheetColumnPort`, updates the correction state, and returns the full updated mapping for re-confirmation. If the column does not exist, it returns the list of available columns.

- **Architectural layer:** `Application`

- **Acceptance criteria:**
  - [ ] Use case accepts user/session identifier and correction message.
  - [ ] It delegates parsing to the natural-language correction parser.
  - [ ] It validates the new column against available columns from the spreadsheet.
  - [ ] On valid correction, it accumulates the change and returns the updated mapping.
  - [ ] On invalid column, it returns an error with available column list.

- **Technical dependencies (block the start):** T-4.06-02, T-4.06-04
- **Delivery dependencies (block the merge):** T-4.06-07, T-4.06-08

- **Estimation:** 2 hours

- **Suggested role:** Backend

- **Technical notes:** The use case contains all business logic: parsing, validation, state update. It uses ports only; actual spreadsheet and storage implementations are in Infrastructure.
