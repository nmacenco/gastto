### Task T-4.06-02: Define application ports for mapping persistence and column listing

- **Description:** Define the driven ports that the application use cases need: a `MappingRepository` to load/save the proposed and confirmed mapping, a `ConversationStateRepository` to persist the correction state, and a `SpreadsheetColumnPort` to query available columns from the user's sheet. Declare these as interfaces in the Application layer.

- **Architectural layer:** `Application`

- **Acceptance criteria:**
  - [x] `MappingRepository` port declares methods to load proposed mapping and save confirmed mapping.
  - [x] `ConversationStateRepository` port declares methods to save/load correction state with TTL support.
  - [x] `SpreadsheetColumnPort` port declares a method to list available columns in the selected sheet.
  - [x] Ports are located under `src/application/ports/` or equivalent.

- **Technical dependencies (block the start):** T-4.06-01
- **Delivery dependencies (block the merge):** T-4.06-03, T-4.06-05, T-4.06-06

- **Estimation:** 1 hour

- **Suggested role:** Backend

- **Technical notes:** Keep ports framework-agnostic. TTL for Redis keys can be configured via `src/config/`. Existing adapters under `src/infrastructure/adapters/` should implement these interfaces later.
