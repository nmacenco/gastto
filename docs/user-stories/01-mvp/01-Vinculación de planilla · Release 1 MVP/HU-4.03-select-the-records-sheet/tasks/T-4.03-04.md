### Task T-4.03-04: Implement HandleSheetSelection use case

- **Description:** Implement the `HandleSheetSelection` use case in the Application layer that orchestrates the `ONBOARDING_SHEET` state. The use case receives the user's raw message, the selected file metadata (from `statePayload` left by HU-4.02), and the decrypted OAuth token. It calls `SpreadsheetPort.listSheets` to discover available sheets, then branches according to the Gherkin scenarios: single-sheet auto-confirmation, numbered list selection, fuzzy name matching, header-based description for "I don't know", and re-prompt for invalid names. After confirmation, it calls `ISpreadsheetConfigRepository.create` to persist the `spreadsheet_configs` record with `sheetName` and a placeholder `accessVerifiedAt`, then transitions the FSM to `ONBOARDING_MAPPING`. The route handler (Interfaces layer) **only** deserializes, validates, and delegates to this use case. All business logic lives in the Application layer.

- **Architectural layer:** `Application`

- **Acceptance criteria:**
  - [ ] `HandleSheetSelection` class exists in `src/application/use-cases/spreadsheet/HandleSheetSelection.ts`.
  - [ ] Input/output DTOs defined with fields: `userId`, `rawMessage`, `externalId`, `channel`, `statePayload`.
  - [ ] Single-sheet case: auto-confirms, persists, and transitions to `ONBOARDING_MAPPING` without user interaction.
  - [ ] Multi-sheet case: lists sheets by name, accepts number or name.
  - [ ] Fuzzy name matching normalizes input (lowercase, unaccented) before comparing.
  - [ ] "I don't know" variant triggers `getHeaders` for each sheet and formats a description for the user.
  - [ ] Invalid name triggers re-prompt with the list again.
  - [ ] On confirmation, `ISpreadsheetConfigRepository.create` is called with `fileId`, `fileName`, `sheetName`, `provider`, and placeholder `accessVerifiedAt`.
  - [ ] FSM transitions to `ONBOARDING_MAPPING` via `TransitionConversationState`.
  - [ ] Unit tests cover all 5 Gherkin scenarios and error paths (token expired, API failure).
