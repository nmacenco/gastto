### Task T-4.04-03: Implement Excel Online preview and write-permission adapter

- **Description:** Implement the Excel Online (OneDrive/SharePoint) adapter that fulfills the `ValidateSpreadsheetAccessPort` driven port. The adapter must: (1) read the first 10 rows of the selected sheet via the Microsoft Graph API, (2) detect if the sheet is empty, (3) verify write permissions by checking item capabilities or attempting a lightweight write probe. Handle network errors and expired/invalid tokens, returning structured `SpreadsheetAccessResult` values. All Microsoft-specific logic must be isolated in this adapter.

- **Architectural layer:** `Infrastructure`

- **Acceptance criteria:**
  - [x] Adapter implements `ValidateSpreadsheetAccessPort` interface.
  - [x] Reads first 10 rows from Microsoft Graph API successfully.
  - [x] Detects empty sheet and returns `empty-sheet` result.
  - [x] Verifies write permission and returns `read-only` result when lacking write access.
  - [x] Returns `access-error` result with descriptive error type on network failure or expired token.
  - [x] No Microsoft-specific types leak into domain or application layers.
  - [x] Unit tests with mocked Graph API client cover all four result variants.

- **Technical dependencies (block the start):** T-4.04-01
- **Delivery dependencies (block the merge):** T-4.04-05

- **Estimation:** 2.5 hours

- **Suggested role:** Backend

- **Technical notes:** Place adapter under `src/infrastructure/adapters/sheets/` (alongside or in a parallel folder to the Google adapter). Follow existing adapter patterns. Use the project's Microsoft OAuth token management. Refer to `AGENTS.md` infrastructure adapters section. Mock the Graph API client in tests — never call real APIs.
